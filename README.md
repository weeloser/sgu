# СГУ Элина // БАРС & СМЕРЧ (Android)

Полнофункциональный виртуальный пульт управления специальными звуковыми и световыми сигналами (СГУ) для Android, разработанный на Kotlin и Jetpack Compose с низколатентным программным DSP-синтезатором звука в реальном времени.

## Основные возможности

- **HORN 70HZ (КРЯК «ЭЛИНА»)**: Аутентичный звук горна с жесткой модуляцией 70.8 Гц, тремоло и акустической фильтрацией металлического рупора ГРД-100 с компрессионным насыщением (tanh distortion).
- **MANUAL (РУЧНОЙ ПОДВЫВ)**: Инерционный разгон сирены при зажатии клавиши (570 → 1620 Гц) и реалистичный спад до 450 Гц при отпускании.
- **СЕТКА СИРЕН (ГОСТ Р 50574, комплекс «Смерч»)**:
  - **WAIL 1**: ГОСТ 4.4 сек (600–1580 Гц).
  - **WAIL 2**: Скоростной 2.7 сек (680–1680 Гц).
  - **SRT «ПЛАЧ»**: Культовый плачущий спецсигнал с циклом 1.55 сек (взлёт 0.40с + спад 1.15с) и вибрато раструба 5.8 Гц.
  - **YELP**: Быстрая погоня (визг 3.8 Гц).
  - **HI-LO**: Двухтональный сигнал (940 / 680 Гц).
  - **КРЯК ×2**: Синхронизированный двойной предупредительный импульс.
  - **КЛАКСОН**: Двухтональный пневмосигнал (340 + 425 Гц); короткий тап запускает двойной сигнал, зажатие — непрерывный гудок.
  - **ГОРЯЧАЯ 15С**: Режим оперативного преследования с автовыключением через 15 секунд.
- **ТАНГЕНТА МИКРОФОНА PTT**:
  - Радиочирпы ( squelch открытия и закрытия эфира).
  - Запись речи с таймером в реальном времени.
  - Вещание через акустический процессор мегафона 200W (полосовая фильтрация, резонанс рупора и сатурация).
  - Кнопка повтора последней фразы.
- **СГО (СТРОБОСКОПЫ)**:
  - Полноэкранный режим стробоскопов (поочередные вспышки: тройной красный слева, тройной синий справа).
  - Оперативная кнопка «КРЯК» прямо поверх полноэкранного режима стробоскопов.
  - Индикация на верхней панели.
- **VU-МЕТР**: 12-сегментный динамический светодиодный индикатор выходного уровня звука в реальном времени.
